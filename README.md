## About

Hi, I'm Thanabodee. I studied Computer and Information Science and now work as a software developer.

Most of what I build is for the inside of a business — internal web systems, reporting dashboards, and tools that take a manual process and make it less painful. I've also spent a good amount of time on computer vision, mainly using YOLO and OpenCV to detect industrial parts from a live camera feed.

I care about the part before the code, too. Understanding how people actually work usually tells me more about what to build than the spec does.

## Selected Projects

**Vision AI Object Detection** &nbsp;`Python` `YOLOv8` `OpenCV` `Tkinter`
A desktop app that detects and identifies industrial parts in real time from a camera. It includes camera controls, live bounding-box visualization, and a simple interface built for people on the floor rather than developers.

**Business Data Dashboards** &nbsp;`Power BI` `DAX` `Excel`
Interactive dashboards built from raw operational data. The bulk of the work is cleaning and shaping the data so the KPIs at the end are actually trustworthy.

**Employee Management System** &nbsp;`React` `Node.js` `Express` `MySQL`
A full-stack web app for managing employee records, with CRUD operations and role-based access control on top of a MySQL database.

**Phone Number Management App** &nbsp;`Kotlin` `Firebase`
An Android app for adding, editing, and deleting phone number records, synced through Firebase Realtime Database.

## What I'm Working On

## How I Work

Understand the problem → analyze the process → design the system → build → test → improve.

I'd rather ship something simple that people use every day than something clever that nobody opens.
